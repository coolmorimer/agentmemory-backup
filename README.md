# Резервная копия AgentMemory

Приватный репозиторий для переноса памяти AgentMemory между своими Windows-ПК.

## На текущем ПК

Запустите `backup.cmd`. Скрипт:

1. Получит полный экспорт через локальный API AgentMemory.
2. Заблокирует отправку, если обнаружит похожий на секрет ключ или токен.
3. Закоммитит только `memory-export.json` и `backup-meta.json`.
4. Отправит обновление в этот приватный GitHub-репозиторий.

## На другом ПК

Сначала установите и запустите AgentMemory, а также войдите в GitHub CLI:

```powershell
gh auth login
git clone https://github.com/coolmorimer/agentmemory-backup.git
cd agentmemory-backup
.\Restore-Memory.ps1
```

По умолчанию восстановление использует безопасный режим `merge`: добавляет данные и обновляет совпадающие записи, не очищая уже имеющуюся память.

Для следующих переносов достаточно запускать `backup.cmd` на исходном ПК и `restore.cmd` на новом.

## Безопасность

- Репозиторий должен оставаться приватным.
- Файлы `.env`, ключи, логи, бинарники и GitHub-токены сюда не добавляются.
- Экспорт содержит личную историю работы. Не выдавайте доступ посторонним.
